# Task 8 - Capture Network Traffic with Wireshark

## Objective

Capture and analyze network traffic using Wireshark.

## Tools Used

- Wireshark
- Windows 11
- Web Browser

## Procedure

1. Installed Wireshark.
2. Started capture on active Wi-Fi adapter.
3. Generated HTTP traffic using neverssl.com.
4. Applied HTTP filter.
5. Analyzed captured packets.

## Packet Analysis

### HTTP GET Request

Observed an HTTP GET request sent from the client to the web server.

### Host Information

The packet contained destination host details and requested resources.

## Findings

- Successfully captured network traffic.
- Applied HTTP filter.
- Observed HTTP communication.
- Examined packet headers and protocol information.
